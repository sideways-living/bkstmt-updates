# BKSTMT Updates

This public repository contains the Sparkle appcast and signed release assets for BKSTMT.

Application source code is maintained separately in a private repository. Release archives published here must be Developer ID signed, Apple-notarised, stapled, and EdDSA-signed by Sparkle before the appcast is updated.
